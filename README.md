# Приложение для скачивания изображений по API

### Функционал
Проект представляет собой прототип сервиса Unsplash (https://unsplash.com) для поиска и просмотра изображений по запросу.

### Фреймворк и архитектура
Приложение написано на фреймворке UIKit, архитектура - MVVM+С.

### Что используется 

В проекте используются REST API для скачивания данных, а также FileManager и UserDefaults для их хранения и кэширования. Передача данных для отображения реализована через фреймворк Combine, также используются паттерны Builder (для создания модулей) и Coordinator (для переключения между экранами).

### Флоу работы приложения

Главный экран приложения содержит текстовое поле, в которое вводится запрос для поиска изображений: после нажатия кнопки поиска текстовое поле с анимацией поднимается выше, освобождая место для коллекции с изображениями по запросу (при пролистывании срабатает пагинация). В случае отсутствия изображений по запросу выводится соответствующий алерт. 

При нажатии на выбранное изображение можно рассмотреть его ближе в detailView, реализованном а виде модального окна - для возврата на исходный экран достаточно нажать кноку "х". При повторном запросе ранее запрошенных изображений они подтянутся из Репозитория.
