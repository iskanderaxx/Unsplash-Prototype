# Приложение для скачивания изображений по API

### Настоящий проект представляет собой прототип сервиса Unsplash (https://unsplash.com) для поиска изображений по запросу. Приложение написано на фреймворке UIKit, архитектура - MVVM+C. 

В проекте используются REST API для скачивания данных, а также FileManager и UserDefaults для их хранения.
Передача данных для отображения реализована через фреймворк Combine, в проекте также используются паттерны Builder (для создания модулей) и Coordinator для навигации.

Главный экран приложения содержит текстовое поле, в которое вводится запрос: после нажатия кнопки поиска текстовое поле с анимацией поднимается выше, освобождая место для коллекции с запрошенными изображениями. 

При нажатии на выбранное изображение можно рассмотреть его ближе в detailView, реализованном а виде модального окна.
