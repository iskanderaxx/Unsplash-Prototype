## Приложение для скачивания изображений по API

### Функционал
Проект представляет собой прототип сервиса Unsplash (https://unsplash.com) для поиска и просмотра изображений по запросу.

### Фреймворк и архитектура
Приложение написано на фреймворке UIKit, архитектура - MVVM+С.

### Что используется 

В проекте используются REST API для скачивания данных, а также FileManager и UserDefaults для их хранения и кэширования. Передача данных для отображения реализована через фреймворк Combine, также используются паттерны Builder (для создания модулей) и Coordinator (для переключения между экранами).

### Флоу работы приложения

- главный экран приложения содержит текстовое поле, в которое вводится запрос для поиска изображений;
- после нажатия кнопки поиска текстовое поле с анимацией поднимается выше, освобождая место для коллекции с изображениями по запросу (при пролистывании коллекции срабатает пагинация);
- при отсутствии изображений по запросу выводится соответствующий алерт;
- нажатие на выбранное изображение вызывает переход в его detailView, которое реализовано как модальное окно;
- для возврата на главный экран достаточно нажать кноку "х", после чего detailView изображения будет скрыто;
- при повторном запросе ранее запрошенных изображений будет выполнена проверка: уже имеющиеся изображения подтянутся из кэша, остальные будут скачены по API и отражены в коллекции.
